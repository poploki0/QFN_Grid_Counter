Grid Counter

ใส่รูป วางตาราง แล้วกดกากบาทเพื่อคำนวณ %

1. เลือกรูปภาพ

หรือลากไฟล์รูปมาวางในพื้นที่แสดงภาพ

2. ครอปและปรับขนาด

ลากเมาส์บนภาพเพื่อเลือกส่วนที่ต้องการเก็บไว้

เปลี่ยนความกว้างหรือความสูงอย่างใดอย่างหนึ่ง อีกค่าจะปรับตามสัดส่วนให้เอง

3. ตั้งค่า Grid

ผลคำนวณ

0%
0 / (20 × 20) = 0%

คลิกช่องเพื่อใส่หรือลบกากบาท ลากต่อเนื่องเพื่อใส่หลายช่องพร้อมกัน

ยังไม่มีรูปภาพ
